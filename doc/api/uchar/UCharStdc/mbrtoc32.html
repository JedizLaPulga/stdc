Converts a UTF-8 encoded sequence to a char32_t. Returns -1 on encoding error.

Implementation

char32_t mbrtoc32(List<int> s) {
  if (s.isEmpty) return 0;
  try {
    String str = utf8.decode(s);
    if (str.isEmpty) return 0;
    return str.runes.first;
  } catch (_) {
    return -1;
  }
}
