CtypeStdc extension

Extension on Stdc to provide <ctype.h> functionality.

Importing this file attaches standard C character handling functions directly to the global stdc instance.

Note: Since Dart does not have a char type, these functions accept a String. Only the first character (code unit) of the string is evaluated.
